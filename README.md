# Financial Data Analysis & Strategy Testing

A collection of Google Colab / Python notebook projects exploring stock market data, strategy testing, and data-driven experimentation using Yahoo Finance and Dukascopy bank data.

## Overview
This repository contains notebook-based projects created to explore how Python can be used for financial data analysis and simple model/strategy testing.

## Projects Included
- **Stock Data Analysis** – exploring historical stock data and market trends
- **Trading Strategy Testing** – testing simple strategy logic using historical price data

## Tools Used
- Python
- Google Colab
- Yahoo Finance / yfinance / Dukascopy bank financial data
- pandas
- matplotlib
- notebook-based experimentation

## What I Learned
- Working with real-world financial datasets
- Basic data analysis and visualization
- Testing strategy logic with historical data
- Strengthening Python and analytical problem-solving skills

## Note
These projects were created as self-directed learning and experimentation work to build stronger foundations in Python, data analysis, and applied technical thinking.
